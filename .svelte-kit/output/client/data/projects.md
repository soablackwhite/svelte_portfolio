### My Website
**Category:** Web Project  
**Tech:** HTML, CSS, JavaScript, React, Next.js  
![portfolio thumbnail](/media/icons/icon.svg)

This website has become a playground for new ideas. Come back in another two weeks to find components and new ones taking their place. I rewrote this website at least 3 times.

1. First time: not mobile-friendly, just pretty.
2. Second time: shoved old components into an unfit design.
3. Third time: rebuilt everything with a new framework. No mercy for outdated parts.

While minimal, it includes interactive bits showcasing my interest in data viz + design. Large screen = good. Mobile = mid.

#### Design
- **Colors:** Monochrome design pushing hierarchy with just black + white.
- **Customizability:** There's a hidden GUI (ugly but functional) in the GitHub repo.
- **Skill section scroll:** Excessive? Yeah. But this site is a testing ground.
- **Layout:** Central nav, info on left, empty space on right. Inspired by game UI flow.

#### Typewriter
Had prior experience. Reused code (on GitHub).

#### Mobile
The original constellation UI didn’t translate. Killed it and made a separate mobile layout instead.

### 4ELE
**Category:** Web Project  
**Tech:** ml5.js, p5.js, Teachable Machine  
![ML Rock Paper Scissors video](/media/thumbnails/rps.webp)

**4ELE** is a project built with Google's Teachable Machine. Webcam input + image recognition = RPS vs AI.

#### Model
Took thousands of hand gesture pics, varied lighting/angles. Trained the model until accuracy hit good-enough.

#### Art
- Drew pixel art myself.
- Used DALL·E to upscale/supplement.
- Animated with Aseprite manually.

#### Web Port
- Started in p5.js + ml5.js.
- Ported to SvelteKit.
- Used SkeletonUI + TailwindCSS for UI components.

### Reccie
**Category:** Web Project  
**Tech:** p5.js  
![Reccie video](/media/thumbnails/bw/4e.webp)

#### Data Gathering
Made a Google Form: people rate shows/movies with "liked", "haven’t watched", "did not like". Converted to 1, 0, -1.

#### Algorithm
Collaborative filtering—recommendations based on people with similar tastes, regardless of medium. Not scalable, but works with static data.

#### Design
Yellow phone case inspired the app’s color palette.

### Algo Art
**Category:** Generative Art  
**Tech:** Processing, Unity, openFrameworks  
![Algorithm Art video](/media/animated/art_docu.mp4)

**Algo Art** is a project collection that includes:

- **OS GIFs:** My Interactive Media Capstone. Explores open-source by visualizing how algorithms work, not just dumping code.

### postcARds
**Category:** AR App

### Mad Socks
**Category:** Game  
**Tech:** Unity, C#  
![Mad Socks image](/media/thumbnails/bw/madsocks.webp)

**Mad Socks** was built in 3 days during the 2021 Global Game Jam. I did Game Design, Story, and Programming. It was nominated for Best Game Design and Best Art Direction.

Gameplay:  
- Narrative about socks in a washing machine world.  
- Multiplayer top-down maze race to find your pair.  
- When time’s up, the washing machine spins and scrambles your controls.

### Switch
**Category:** Game  
**Tech:** GMS2  
![Switch image](/media/thumbnails/switch.png)

**Switch** is a minimalist 2D platformer made in GMS2. Only two colors used (B/W). Players fight for a ball and whenever one touches it, the entire background switches to their color. Their own character becomes nearly invisible—except for the eyes.
